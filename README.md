# Faculty Annual Performance Appraisal Form (FPAS)

A web-based digital interactive implementation of the Faculty Annual Performance Appraisal System (FPAS) form.

## ✨ Features
- **Print-Exact Format**: Accurately reproduces the official multi-page paper form layout and typography.
- **Interactive & Editable**:
  - Live editable fields across all sections (General Information, Part B contributions, Self-Assessment, HOD Remarks, Final Scoring).
  - Transparent paper-style design with clean, line-free inputs.
  - Centered multiline remarks guidelines that automatically disappear as you type.
- **Smart Scoring & Calculations**:
  - Strict numbers-only validation on score inputs (blocks letters, symbols, and invalid entries).
  - Score capping: Awarded score cannot exceed the maximum score for any activity.
  - Automatic section tally and live grand total / percentage calculation in Part E.
- **Print & PDF Export**: Clean print styling that hides action buttons and ensures a crisp, professional printed appraisal document.

## 🚀 Usage
Simply open `Faculty_Appraisal_Form.html` or `index.html` in any modern web browser.
